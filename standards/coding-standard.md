以下条款是本仓库的默认底线，替换前对 RTL 有约束力。

---

## 1. 文件与命名

1. 一个文件一个模块；文件名与顶层模块名一致（`rr_arbiter.sv` ↔ `module rr_arbiter`）。
2. 目录名用全称（`rr_arbiter`），ID 用 `module.yaml` 里的 `id_short`（`rra`）。
3. 信号命名后缀：

   | 后缀 | 含义 | 例 |
   |---|---|---|
   | `_i` | 模块输入端口 | `req_i` |
   | `_o` | 模块输出端口 | `grant_o` |
   | `_q` | 时序输出（寄存器 Q 端） | `state_q` |
   | `_d` | 时序输入的次态 | `state_d` |
   | `_n` | 低有效 | `rst_n` |
   | `_r` | 寄存器数组/中间寄存 | — |

4. 常量/参数：`UPPER_SNAKE`；类型用 `_t` 后缀（`typedef enum logic [1:0] state_t;`）。
5. 前缀 `u_` 用于实例名（`u_arb_core`）。

## 2. 时序与组合逻辑

1. **只允许** `always_ff` / `always_comb` / `always_latch`（后者默认禁止，出现即 lint 报错）。
2. `always_ff` 内只用非阻塞赋值 `<=`；`always_comb` 内只用阻塞赋值 `=`。**禁止混用**。
3. 禁止组合逻辑产生 latch：每个 `always_comb` 的所有分支必须给同一组信号赋值（用默认赋值兜底）。
4. 敏感列表由 `always_ff @(posedge clk)` / `always_comb` 自动推导，**不要**写 `always @(*)` 或手写列表。
5. 复位：默认**同步复位、低有效**（`rst_n`）。若必须异步，需在该模块详设的「复位与初值」一节写明理由。
6. 一个 `always_ff` 只驱动一组同源的寄存器，禁止把无关逻辑塞进同一块。

## 3. 位宽与类型

1. **禁止隐式位宽**：所有端口、信号、参数显式声明位宽；比较与赋值两侧位宽必须一致。
2. 常量必须带位宽与进制：`4'd0` 而非 `0`；`1'b1` 而非 `1`。
3. 禁止 `integer` 参与可综合逻辑（生成循环的 `genvar`/`int` 除外）。
4. 使用 `logic`，不用 `reg`/`wire` 混写（`wire` 仅用于显式连续赋值场景，且同一文件风格统一）。
5. 截断/扩展必须显式：用 `'{...}`、`$unsigned()`、或先赋给明确位宽的中间信号。

## 4. 结构

1. 端口顺序：`clk` → `rst_n` → 其它输入 → 输出。
2. 参数集中在模块头部，默认值必须可综合；`parameter` 给默认值，`localparam` 用于派生常量。
3. `case` 必须 `unique` 或 `priority`，并写 `default`。
4. 禁止 `initial`（仿真用的除外，且必须放在 `ifdef SIMULATION` 内）。
5. 禁止延时 `#`、`force/release`、`wait`、`fork/join` 出现在可综合代码里。
6. 三目与 `if` 的嵌套不超过 3 层；超出就拆模块或拆信号。
7. 每个模块头部写注释块：功能一句话、时钟域、复位方式、对应的 `DES-*`。

## 5. 可综合性（面向 Yosys + sky130）

1. 不用动态数组、队列、关联数组、`class`、`mailbox`、`semaphore`、`string`。
2. `struct`/`union` 仅在 packed 且目标是 Yosys 可综合范围内使用；不确定就先别用。
3. 存储器阵列若不映射为宏单元，必须在详设里说明「综合为触发器」的代价。
4. 除法/取模、实数、`$rtoi` 等不可综合结构禁止出现在 RTL（仿真 TB 里可以用）。

## 6. 格式

1. 缩进 2 空格，行宽 ≤ 100。
2. 提交前用 `verible-verilog-format` 统一格式（命令见 `gate 04` 输出或 `--dry-run`）。
3. 每个文件末尾一个空行，禁止行尾空白。
